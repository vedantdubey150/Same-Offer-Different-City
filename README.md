# Same Offer, Different City

A UG economics project on why women students in India are less likely than men to take internships in another city.

The site is one self-contained page (`index.html`):

- **Pixel-art room** with clickable objects; scrolling flies through the window into a Bengaluru skyline.
- **The gap** (evidence), **the textbook** (human capital model and why it fails), and **the model** (a rational-choice model with student and parents).
- **Pack Your Bags**, a game priced at real Bengaluru rents and fares, that checks every possible plan for both players.
- **Policy Lab** with sliders, **Voices** interview video player, and a companion note with sources.

To view it, open `index.html` in a browser. To publish it, enable GitHub Pages on this repository (Settings → Pages → deploy from the `main` branch).

The interview video should be added as `voices.mp4` next to `index.html`.
